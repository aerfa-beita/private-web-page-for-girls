# 🌌 我们的宇宙

> 一个属于两个人的小型宇宙 App — 宇宙开场动画 + 浪漫首页

---

## 2026-07-25 状态更新

- 完整回忆档案恢复为 Vercel 静态资源优先：`assets/Photograph/IMG_20260228/` 中 93 张照片由 `image_carousel.js` 懒加载；Firebase 不可用不会影响既有回忆。
- Firebase Storage 仅保留给后续朋友投稿或新增照片，不迁移、不删除现有照片；推送主分支后由 Vercel 随代码一同部署。

- 密码后默认进入可旋转的地球；左侧“地图”标签切换“地球 / 回忆 / 此刻 / 档案”。旅行路线只在选中区域后以描边和移动光点出现，不会常驻遮挡地球。
- 回忆页固定为 6 张纵向拼接的拍立得；完整放映机和照片投稿在独立“档案”模块首次打开时初始化。
- “此刻”页面以无边框画布保持左心形、右双城天气：单人显示未合拢的金色星尘心；在线侧光点抵达心边缘时才短促震颤，第二位不同访客在线后才完整点亮；上海、成都天气上下排列并保留接口降级文案。
- 解锁后默认进入全视口流动星河：白金星尘以横向光带缓慢经过，并与全站宇宙背景连续铺满；四颗真实天体以渐隐暗面融入星云，默认呈现“星辰手记”名称，点击后才展开专属情话与轨道；鼠标或手指移动时以低负载单粒金银星尘留痕，3.2 至 5 秒淡出。
- 留言位于独立“档案”模块并支持每页 12 条；服务异常时公开页面静默隐藏，不向访客暴露调试提示。需要本地测试时，在未提交的 `config.js` 中设置 `ENABLE_MESSAGE_TESTING: true`。
- 开场在页面真正可见后才开始字幕时序；生成星图 `celestial-atlas-cloud-drift.png?v=2` 直接由 CSS 设为默认背景，并作极轻微漂移，音乐列表与当前 MP3 文件名一致。
- 朋友照片投稿已完成前端的压缩、限额、待审核流程；上线前仍须在 Firebase 控制台发布仓库内的 Firestore 与 Storage 规则并做真机验收。

正式交付前如需清除测试留言，必须先由项目所有者确认，再在 Firebase 控制台清理 `messages` 集合；本仓库不会自动删除任何留言数据。

## ✨ 功能

### 🚀 宇宙开场动画（V2 新增）
- 黑幕字幕镜面碎裂后汇聚为第一颗星 → 原生流星、星野、镰刀星与透明狮子座 → 星点密码 → 银河收拢为主页。
- 首次点击才启动原生 Three.js 模块；电影文字层在约 1.15 秒后退出。原生月亮位于狮头朝向外的右上留白区，并以低饱和香槟色和弱外晕融入画面；狮子座时间轴不变。
- 音乐只会在点击第一颗星后渐入；初始黑幕不展示按钮、标题或首页 UI。

### 🔒 安全锁
- 密码显示为逐颗点亮的星点，实际仍校验 `SECRET_CODE`；密码长度可配置
- 从密码页返回星光后，可再次点中心恒星打开密码星点
- 密码正确才进入主应用

### 🏠 宇宙首页（V2 新增）
- 中央呼吸星球 + 相遇天数（自 2025-01-29 起自动计算）
- 三个星球入口卡片：📖 时间星河 / 🌱 成长星球 / 💌 写给你的信

### 📖 时间星河（原时光回放机）
- 照片回忆墙（每组 3 张、随机洗牌、手动翻页、自动轮播）
- 时间星河：按照片日期排列的回忆卡片
- 拍立得照片样式，并支持减少动态效果偏好
- 背景音乐随机播放（暂停/下一首）
- 每日情话（本地预设 + Hitokoto API，30 分钟切换）
- 生日检测：匹配预设生日 → 全屏祝福 + 花瓣粒子 + 语音；关闭后会释放动画和窗口监听
- Firebase 在线心跳检测

### 🌱 成长星球（原秘密基地）
- 留言板：文字留言（Firebase Firestore）
- 留言访问：页面自动进行 Firebase 匿名登录，Firestore 仅接收已认证匿名用户的合规请求
- 图片留言上传：Storage 已配置，前端上传流程待实现
- 留言列表实时更新（倒序）、CSS 树 + 叶子动画
- OpenWeatherMap 双城市天气 + 随机提示语；未配置时显示页面内提示，不发送空 Key 请求
- 留言星星树：每条 Firestore 留言映射为一颗展示星星
- 星语小助手：仅通过同源服务端代理调用，离线时保留回忆浏览

### 💌 月光来信
- 开场右上角月亮长按，完成进度环后打开一封随机情书
- 优先读取 `config.js` 中的 `MOON_LETTERS`；未配置时回退到 `LOVE_QUOTES`

### ♌ 狮子座静观页（V3）
- 密码解锁后以短暂星图过渡自然上划进入首页；触摸或键盘可立即跳过
- 三颗主星铭刻关键日期与私人回忆，沙漠和重庆节点展示现有照片碎片
- 可按住星图左右拖动，以克制角度欣赏星座轮廓
- 三段记忆采用纵向日期与文案排版，避免文字重叠

### ♌ 透明狮子座融合（2026-07-19）
- 开场先逐颗点亮包含轩辕十二的六颗镰刀星，再淡入透明底的精细金线狮子
- 解锁后的星图复用同一张透明线稿，避免任何图片贴图感
- 标题、主视觉与解锁提示分为上、中、下三区，避免重叠
- 离开静观页后卸载全部开场视觉，照片和其他内容页不再出现狮子座背景
- 引导流星落到入口后才显示“轻触星空”；月亮长按带进度环并打开随机情书
- 开场流星从第一秒划过，狮子座以暗金到清晰的连续显影完成主视觉
- 开场节奏为流星 → 主星连续连线 → 狮子显形；Service Worker 会随每次用户可见发布递增版本
- Three.js 不可用时自动保留标题、月亮与静态狮子座的完整备用开场，不再只显示空星空

### V4 验收流程

- 每项 V4 视觉改造在独立工作树开发，确认后才合并

### 🖼 回忆放映机
- 93 张 Vercel 静态照片轮播（首次进入该模块才动态注入、unseen-first 优先展示未看过的）

## 🛠 技术栈

| 技术 | 用途 |
|------|------|
| HTML5 + CSS3 + Vanilla JS | 主体（单文件架构） |
| Three.js r128 (CDN) | WebGL 宇宙开场动画 |
| Firebase Realtime Database | 在线状态监听 |
| Firebase Firestore | 留言数据存储 |
| Firebase Authentication（匿名） | 留言访问身份与 Firestore 规则校验 |
| Firebase Storage | 后续朋友投稿待审核路径与图片读取（既有 93 张档案不依赖它） |
| OpenWeatherMap API | 天气数据 |
| Service Worker + Manifest | PWA 离线支持 |

## 🚀 快速开始

### 1. 替换配置
打开 `index.html`，搜索 `【配置区】` 修改页面内容；Firebase 公开连接配置在 `firebase-config.js`，私密配置在不会发布的 `config.js`。

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `SECRET_CODE` | 密码锁密码 | `"0729"` |
| `BIRTHDAY` | 生日 (MM-DD) | `"07-29"` |
| `LOVE_START_DATE` | 相遇日期 | `"2025-01-29"` |
| `FIREBASE_CONFIG` | Firebase 项目公开网页配置（`firebase-config.js`） | ... |
| `WEATHER_API_KEY` | OpenWeatherMap Key | ... |
| `photos` | 照片数组 | 6 张（2 组 × 3） |
| `LOVE_QUOTES` | 情话语录 | 10 条 |
| `MOON_LETTERS` | 月亮长按的专属情书（`config.js`） | 可选，优先于 `LOVE_QUOTES` |
| `MUSIC_PLAYLIST` | 音乐列表 | 8 首 MP3 |

`firebase-config.js` 已随项目发布，只保存 Firebase 网页连接配置；`config.js` 可在本地覆盖密码和私人情书。线上天气 Key 由 `/api/config` 异步提供，密码仍静态回退为 `0729`；未配置 Firebase 或天气时，页面会保留浏览体验并显示对应的服务未配置状态。

### 2. 准备资源
- `assets/Music/` — 背景音乐文件
- `assets/Photograph/` — 照片文件
- `assets/blessing.mp3` — 生日祝福语音
- `assets/icon-192.png` / `icon-512.png` — PWA 图标

### 3. 运行
- **本地测试**：在独立 worktree 中运行 `node serve-local.js 5174`，再打开 `http://127.0.0.1:5174/`；本地预览会禁用 PWA 缓存，避免旧版本干扰。
- **上线**：Vercel / GitHub Pages（自动 HTTPS）
