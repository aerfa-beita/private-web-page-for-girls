## 三、lion_background.js V2 架构

### 3.1 模块结构

```
lion_background.js (IIFE)
├── loadThree(callback)          — CDN 动态加载 Three.js r128
├── createScene()                — 创建 {scene, camera, renderer}
├── createStarLayers(scene)      — 三层星空系统
│   ├── 第一层：普通星 3000 颗 (opacity 0.4)
│   ├── 第二层：亮星 500 颗 (opacity 0.8)
│   └── 第三层：特殊星 50 颗 (狮子座周围)
├── createGalaxy(scene)          — 银河旋臂
│   ├── 4 条旋臂、8000 粒子 (电脑) / 2000 (手机)
│   └── 极坐标布局 + 旋转动画
├── createLeoConstellation(scene) — 狮子座星座
│   ├── 7 颗真实恒星 (轩辕十四/十二、五帝座一等)
│   ├── 光晕层 (AdditiveBlending)
│   ├── 连线 (LineBasicMaterial, 粉色)
│   └── 呼吸动画 (scale 1~1.04)
├── createMoon(scene)            — 月亮
│   ├── SphereGeometry + 双层光晕
│   └── 位置 (320, 240, -200)、缓慢漂移
├── initMeteorPool(scene)        — 流星对象池
│   ├── MAX_METEORS 20 (电脑) / 10 (手机)
│   └── 生命周期：inactive → active → fade → inactive
├── createHeartStars(scene)      — 爱心星团彩蛋
│   ├── 200 粉色粒子、心形参数方程
│   └── 4 阶段：idle → appearing → holding → fading
├── introAnimation(...)          — 开场时间轴控制器
│   ├── 0~1.5s：星星渐显
│   ├── 1.5~4s：银河渐显
│   ├── 3~6s：狮子座渐显
│   ├── 4~8s：月亮渐显
│   ├── 1s/3s/6s：三颗序章流星
│   ├── 7s：文字出现
│   └── 9s：dispatchEvent('spaceReady')
└── animate()                    — 主渲染循环
    ├── 星空旋转、银河旋转
    ├── 狮子座呼吸、月亮漂移
    ├── 流星更新（空闲模式随机生成）
    └── 爱心彩蛋更新
```

### 3.2 关键技术点

- **Three.js r128**：CDN 动态加载，失败自动回落 CSS 星空
- **AdditiveBlending**：所有粒子使用加法混合，模拟真实光效
- **性能检测**：`window.innerWidth < 600` 自动降低粒子数（约降 60%）
- **通信协议**：CustomEvent `"spaceReady"` → index.html 接收后显示密码锁
- **月亮彩蛋**：右上角区域点击 5 次触发爱心星团

### 3.3 移动端适配

| 参数 | 桌面端 | 移动端 (<600px) |
|------|--------|-----------------|
| 星空一层 | 3000 | 1500 |
| 星空二层 | 500 | 250 |
| 星空三层 | 50 | 25 |
| 银河粒子 | 8000 | 2000 |
| 流星池 | 20 | 10 |
| 粒子大小 | 1.8~3.5 | 3.0~4.5 |

## 五、事件通信协议

```
lion_background.js                    index.html
     │                                     │
     │  introAnimation() 9s 完成             │
     │                                     │
     │── window.dispatchEvent(              │
     │     new Event("spaceReady")          │
     │   ) ──────────────────────────────→  │
     │                                     │  window.addEventListener(
     │                                     │    "spaceReady",
     │                                     │    () => 显示密码锁
     │                                     │  )
```
