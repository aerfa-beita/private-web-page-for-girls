# 重复进入密码入口

## 问题

“轻触星空”入口使用一次性 `pointerdown` 监听。首次打开密码页后，该监听已被消费；从密码页点击返回只重新显示按钮，没有重新绑定监听，因此第二次轻触无效。

## 处理

- 密码返回按钮发出 `unlockPromptRequested` 事件。
- 启动逻辑监听该事件，并重新执行 `waitForUnlockGesture()`。
- 每次显示入口都会绑定一枚新的单次手势监听，避免重复触发，同时支持任意次数返回与再次进入。
- Service Worker 缓存升级为 `our-universe-v23-repeatable-unlock`。
