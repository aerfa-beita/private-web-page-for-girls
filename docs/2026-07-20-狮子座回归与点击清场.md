# 2026-07-20 狮子座回归与点击清场

## 目的

电影式开场不取消狮子座。正确的叙事是：前段文字建立情绪，第一颗星由她亲手点亮，星空与银河诞生后，狮子座从星点里显影，和“照亮了我的宇宙”等文字共同成为主视觉。

## 实现

- `#cinematic-leo` 使用仓库已有的本地透明线稿 `assets/Leo/leo-linework-transparent.png?v=15`。
- 它只在 `#cinematic-opening.is-galaxy-born` 后淡入；银河收拢到主页时一同缩小淡出。
- 不重新加载 `lion_background.js` 或 Three.js，因此不会把旧开场的网络依赖和加载失败风险带回首屏。
- 第一颗星点击时，`setCaption('', false)` 会立即清空“请亲手点亮它”和“轻轻点一下”对应的引导，不让它们留在光波和银河阶段。

## 验证

- `node --check scripts/opening/cinematic-opening.js`
- `node --check scripts/opening/opening-flow.js`
- `node --test tests/site-features.test.js`：21 项通过。
- 本地 `127.0.0.1:5174` 实测：首星可点击，点击后标题为空；约 3.3 秒后狮子座元素存在且计算透明度为 `0.72`。

## 视觉待验收

需要小花先生确认狮子座的显影大小、亮度和与两段情绪文案的相对位置；功能逻辑已固定在当前 worktree，未触碰主目录。
