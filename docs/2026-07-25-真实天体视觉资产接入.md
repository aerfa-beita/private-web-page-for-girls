# 2026-07-25 真实天体视觉资产接入

## 目标

保持现有真实星云背景 `celestial-atlas-cloud-drift.png` 与 Canvas 横向银河不变，替换四颗 CSS 渐变球，消除“塑料球 / 游戏 UI”质感。

## 实现

- 新增 `assets/planets/` 四份带透明通道的天体视觉资产：
  - `first-light-v2.png`：暗面渐隐的类地星，保留单侧晨光；
  - `dream-realm-moon-v4.png`：与紫雾分离的朦胧月面；
  - `heart-trace-v2.png`：暖白、暗金与少量粉紫的近恒星行星；
  - `eternal-pact-v2.png`：蓝灰气态行星与弱反光星环。
- `scripts/ui/earth-atlas.js` 的 `GALAXY_PLANETS` 为每颗天体声明独立 `asset`，动态生成 `<img class="planet-asset">`。
- CSS 只承担距离感、克制光晕、悬停放大、点击轨道与信息展开；不再用渐变、伪元素纹理或白色描边伪造星球表面。
- 四颗均默认显示“星辰手记 / 中文名 / 英文档案名”；点击后才展开私密文案，并且只有当前天体显示轨道与粒子爆发。

后续实页检查发现旧首页的通用 `.planet` 样式会泄漏进该组件；其隔离、暗面渐隐与拖尾降载见 `2026-07-25-天体暗面融合与低负载星尘.md`。

## 缓存

- 当前页面脚本版本为 `scripts/ui/earth-atlas.js?v=12`。
- 当前 Service Worker 缓存为 `our-universe-v64-dissolved-night-sides`，并预缓存四份当前天体视觉资产。

## 待人工视觉验收

1. 在 `http://127.0.0.1:5174/` 解锁后确认背景首次打开即可出现，横向银河仍铺满视口。
2. 确认四颗天体不再呈现纯黑渐变圆球；第一束光应以暗面和晨光为主。
3. 确认梦境之境更像被紫色雾气包裹的远方天体，而不是完整紫色按钮。
4. 悬停任一颗只产生轻微放大；点击后只展开当前天体的轨道、文案与星尘爆发。
5. 在手机上确认四颗天体、名称与文案不发生遮挡。
