# 开场融合设计

**状态：已确认设计，尚未实施。**

## 目标

将 `intro.js`、`intro.css`、`star_awakening.js` 融入“我们的宇宙”网页，同时不删除现有首页、密码锁、生日、音乐、留言、回忆等功能。

## 已确认约束

- `lion_background.js` 是唯一的入口状态机。
- 在 `lion_background.js` 中新增 `window.universeEntrance` 兼容 API，由它委托狮子座开场状态机。
- `lock-screen` 保留现有 DOM、密码校验和错误提示。
- 页面加载后自动播放 intro；intro 出现提示后，等待用户点击再进入密码阶段。
- 密码正确后，由 `universeEntrance` 调用 `starAwakening()`。
- `starAwakening()` 结束时触发 `leoAwaken`。
- `lion_background.js` 监听 `leoAwaken`，生成狮子座后才交还原有静观页与主页初始化。

## 状态流

```text
INTRO
  └─ intro 自动播放，用户点击提示
       ↓
PASSWORD
  └─ 显示保留的 lock-screen，校验密码
       ↓
AWAKENING
  └─ starAwakening() 执行并触发 leoAwaken
       ↓
LEO
  └─ lion_background.js 生成狮子座
       ↓
UNIVERSE
  └─ 激活原有静观页、首页、生日、音乐与其余既有功能
```

## 文件职责

| 文件 | 改造职责 |
| --- | --- |
| `index.html` | 引入 intro 样式和脚本；加入 intro DOM；保留密码 UI 与原有功能；正确密码时只调用 `universeEntrance.unlock()`。 |
| `intro.css` | 提供 intro 图层、画布、文案和点击提示样式。 |
| `intro.js` | 改为由 lion 启动的受控动画；点击后通知状态机、淡出并停止渲染；不得直接打开密码锁。 |
| `star_awakening.js` | 保持星尘视觉，确保一次性执行、清理画布，并在结束时触发 `leoAwaken`。 |
| `lion_background.js` | 实现 `INTRO → PASSWORD → AWAKENING → LEO → UNIVERSE`；暴露 `window.universeEntrance`；管理 `spaceReady`、`leoAwaken` 和原有狮子座渲染。 |
| `sw.js` | 加入三份新资源并升级缓存名称。 |
| `tests/site-features.test.js` | 覆盖资源加载、入口状态顺序、密码正确后的单一调用链、`leoAwaken` 所有权与离线缓存。 |

## 兼容原则

- 不在 `index.html` 重建第二套入口逻辑。
- `spaceReady` 仅在 lion 将状态转入 `PASSWORD` 后触发，以兼容现有密码锁显示逻辑。
- 原有 `initLionBackground()` 保留；新 `universeEntrance` 是由 lion 提供的兼容接口，不替换已有渲染能力。
- 狮子座生成完成前不启动原有首页初始化，避免密码正确后视觉跳转。

## 验收

1. 首次加载自动播放 intro，点击后才显示密码锁。
2. 错误密码保持原有提示和抖动。
3. 正确密码依次经历星尘觉醒、`leoAwaken`、狮子座生成、原有页面解锁。
4. 刷新、重复点击和重复提交不产生叠加画布、重复事件或重复初始化。
5. Service Worker 离线缓存涵盖新增资源。
6. 通过 JavaScript 语法检查、完整功能测试和桌面/移动端视觉验收。
