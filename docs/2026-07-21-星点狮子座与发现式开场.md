# 2026-07-21 星点狮子座与发现式开场

> 历史误实现：本方案中的内联 SVG 已移除，现由 [复用既有狮子座实现](2026-07-21-复用既有狮子座实现.md) 取代。后续请只修改 `lion_background.js` 内既有的 Three.js 狮子座数据与显影函数。

## 设计修正

开场不再把透明狮子座线稿整张淡入。狮子座改为十颗主星按顺序点亮、三段金色细线依次连接；用户看到的是星座被点亮的过程，而不是一张图片出现。

## 新时间轴

| 时间 | 内容 |
|---|---|
| 0–2 秒 | `#05060A` 黑幕、极弱颗粒与呼吸，无音乐。 |
| 2–5 秒 | 一颗远处小星靠近。 |
| 5–8.5 秒 | “有人，轻轻想起了你。”淡入后淡出。 |
| 9.6–14.5 秒 | 星星抵达中央；“于是，宇宙亮起了第一颗星。”在下方出现。 |
| 16 秒后 | 只剩跳动的星与“轻轻碰一下它”；此时才可点击。 |
| 点击后 | 心跳、三圈光波、音乐渐入、星空与银河生成。 |
| 点击后 4.5 秒 | 十颗星逐颗亮起，三段线依次连成狮子座。 |
| 点击后 9 秒 | 保留原有星点密码入口；密码正确后银河与星座一同收拢为主页。 |

## 实现边界

- `scripts/opening/cinematic-opening.js` 只管理状态与时间轴。
- `index.html` 的 `.cinematic-constellation` 是内联 SVG；没有 Three.js、CDN 或额外图片请求。
- 所有动效只改变 `transform`、`opacity`、`stroke-dashoffset` 与 `filter`，缓动统一为 `cubic-bezier(.22,.61,.36,1)`。
- 脚本版本改为 `cinematic-opening.js?v=2`，Service Worker 缓存升级为 `our-universe-v29-constellation-opening`，防止线上继续命中旧开场。
