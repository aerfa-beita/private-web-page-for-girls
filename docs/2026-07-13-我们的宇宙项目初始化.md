## 一、项目概述

"我们的宇宙"是一个双模块浪漫风格网页应用，所有代码在单个 `index.html` 中完成（内联 CSS 和 JS），配合 Firebase 后端 + OpenWeatherMap API，支持 PWA 离线访问。

## 二、架构决策

| 决策 | 选择 | 原因 |
|------|------|------|
| 代码组织 | 单文件 index.html（内联 CSS + JS） | 无需构建工具，双击即用，方便修改 |
| CSS 方案 | 纯 CSS 变量 + 移动优先 @media | 简洁，无框架依赖 |
| 后端 | Firebase（Realtime DB + Firestore + Storage） | 免费额度够用，实时同步开箱即用 |
| 天气 API | OpenWeatherMap | 免费，中文支持好 |
| 密码锁 | 前端明文变量 `SECRET_CODE` | 非安全场景，仅作仪式感入口，无需后端校验 |
| PWA | Service Worker CacheFirst 策略 | 缓存静态资源，离线可访问 |
| 图标 | 占位 PNG 路径 | 小花先生自行替换 |

## 四、各模块实现要点

### 4.1 星空背景
- CSS `radial-gradient` 多层叠加模拟星云底色
- JS `setInterval` 每 200ms 随机生成光点 DOM 元素，CSS animation 控制闪烁周期

### 4.2 密码锁
- 全屏 `position: fixed` 遮罩，毛玻璃 `backdrop-filter: blur()`
- 错误时 input 抖动（CSS `@keyframes shake`）
- 正确后 `display: none` 隐藏遮罩

### 4.3 照片回忆墙（2026-07-13 更新）
- 所有照片随机洗牌 → 每 **3 张一组** → 手动翻页切换
- 播完所有组后自动重新洗牌，确保每次排列不同
- 移动端纵向堆叠，桌面端 3 列并排（最大宽度 1000px）
- 自动轮播 6 秒翻一组，支持手动 ◀ ▶ 翻页
- 每组一个圆点指示器

### 4.4 背景音乐（2026-07-13 更新）
- 解锁密码后自动随机播放一首（利用用户点击事件绕过浏览器拦截）
- 暂停/播放 + 下一首双按钮
- 洗牌播放列表，播完一轮自动重新洗牌循环
- 不支持格式（flac 在 Safari）自动跳过

### 4.5 流星特效（2026-07-13 新增）
- CSS `@keyframes meteorFall` + JS 定时生成流星 DOM 元素
- 每 4~10 秒从屏幕右上方划出，带渐变拖尾效果

### 4.6 全屏模式（2026-07-13 新增）
- 密码正确进入主应用后自动触发 `requestFullscreen()`

### 4.7 每日情话（2026-07-13 新增）
- 首次进入从 `LOVE_QUOTES` 数组随机取一条展示
- 之后每 30 分钟随机切换：50% 数组 / 50% Hitokoto API（分类 `j` 网易云）
- API 失败时自动回落数组

### 4.8 生日检测
- 每次页面加载时 `new Date()` 取 `MM-DD` 比对 `BIRTHDAY`
- 匹配时弹出全屏弹窗
- Canvas 绘制花瓣粒子：粉色椭圆沿贝塞尔曲线飘落
- 自动播放 `assets/blessing.mp3`

### 4.9 在线状态
- Firebase Realtime Database `ref('.info/connected')` 监听
- 用户在线时写入 `status/{userId}` 节点，`onDisconnect` 自动清除
- 对方节点存在 → 显示心跳动画（CSS `@keyframes heartbeat`）

### 4.10 留言板
- 文字用 `<textarea>`，~~图片用 `<input type="file">`~~
- 🔒 **图片上传暂禁用**（Firebase Storage 需 Blaze 计划绑卡）
- 图片上传代码已注释保留，开通后取消注释即可恢复
- `onSnapshot` 监听 `messages` 集合，`orderBy('createdAt', 'desc')` 倒序
- 新留言时调用 `updateTreeLeaves()` 给 CSS 树加新叶子

### 4.11 CSS 树
- 树干 + 树冠纯 CSS 绘制
- 叶子：`position: absolute` 的 `<span>` 元素，随机颜色/位置/旋转
- 生长：`setInterval` 缓慢增大树冠 `transform: scale()`

### 4.12 天气
- `fetch()` 调用 OpenWeatherMap Current Weather API
- 显示温度、天气描述、城市名
- 随机从 `MESSAGE_TIPS[]` 取一条提示语

### 4.13 PWA
- `manifest.json`：`name="我们的宇宙"`，`theme_color="#1a1a2e"`，`display=standalone`
- `sw.js`：`install` 事件缓存 `CACHE_FILES`，`fetch` 事件 `cacheFirst` 策略
