# 2026-07-21 复用既有狮子座实现

## 修正原因

开场曾短暂新增一份内联 SVG 狮子座。它与项目已有的 Three.js 狮子座重复，星点、连线和动效均无法保持一致，因此已移除。此文档是当前唯一有效的狮子座开场实现说明。

## 唯一的狮子座来源

- `lion_background.js` 是唯一来源；仅按视觉验收要求调整原生月亮至狮头朝向外的右上留白区、缩放与低饱和材质。
- 模块保留原有 `createLeoConstellation(scene)`、透明主视觉 `leo-linework-overlay`、狮子座材质、连线与时间轴；仅月亮采用已验收的右上低饱和构图。
- `bootstrap()` 只在收到 `openingRitualFirstLight` 后调用 `window.initLionBackground()`；事件桥接在模块外，模块内部状态不改。

## 图层与节奏

`#cinematic-opening` 仅负责黑幕、文字、首星和点击；它覆盖在原生狮子座模块上。点击后自身背景与 DOM 星点淡出，露出已按原逻辑完成的狮子座画面。

密码层仍保留，且 `#lock-screen` 的层级高于电影开场层，狮子座完成后再显示星点密码。
