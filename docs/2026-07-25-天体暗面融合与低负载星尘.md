# 2026-07-25 天体暗面融合与低负载星尘

## 问题

真实天体资产接入后，星河页仍显示四个大号深色圆盘，并在行星中央出现 `01 · 29` 与默认椭圆线。紫色天体的雾与月面也混为一个紫色球体；金银拖尾在连续移动时粒子过多。

## 根因

`index.html` 旧首页使用了通用 `.planet`、`.planet::before`、`.planet::after`。`earth-atlas.js` 复用了同一个类名，但没有重置旧的内阴影、日期伪元素与轨道伪元素，导致旧样式泄漏进四颗天体。

## 修复

- 在 `.earth-atlas .planet` 中明确清除旧的 `box-shadow`、圆角及两个伪元素，真实天体不再继承日期和深色圆盘。
- 新增暗面融合资产：第一束光、心动轨迹、永恒之约根据像素亮度降低最暗区域的 Alpha，使暗面自然消散到真实星云背景，不形成外框。
- 梦境之境改为独立的 `dream-realm-moon-v4.png`，紫雾由后层不规则 CSS 星云单独绘制，不再包裹成一个完整紫球。
- 星尘拖尾降为每次采样单粒：采样距离 42px、间隔 80ms；桌面上限 82 粒、移动端上限 52 粒；忽略合并事件中的中间点并降低星芒比例与阴影。
