# 2026-07-23 星尘轨迹与流动星河

## 目标

- 指针或手指移动时，留下金色与银色交织的星尘；粒子缓慢飘散、旋转、淡出，生命周期为 3.2 至 5 秒。
- 密码解锁后的默认“地球”模块改为沉浸式流动星河，保留现有模块导航抽屉。
- 星河中设置可配置的行星彩蛋；悬停显示名称，点击或触摸触发彩色粒子爆发与私密情话弹窗。

## 实现

- `scripts/ui/stardust-trail.js?v=2` 使用一个不拦截事件的固定 Canvas。按移动距离与时间低密度采样：每次只生成 2 至 3 粒，桌面端最多 170 粒、移动端最多 110 粒；只在主体验解锁后启用，尊重减少动态效果设置。
- `scripts/ui/earth-atlas.js` 改为本地 Canvas 星河。桌面端生成 460 颗、移动端 220 颗独立相位粒子，形成四臂旋涡并缓慢流动；模块隐藏或页面不可见时停止绘制。
- `GALAXY_PLANETS` 集中管理行星名称、位置、主色与文案，可直接扩充。当前包括“第一束光”“山海之间”“晚风星”“明天的月亮”。
- 星球、弹窗和引导只用细线、光晕、颜色与排版，不使用表情符号；首颗星球在页面载入两秒后以轻微光晕引导。
- 星河模块解除全局 `.module-page` 的桌面 `1100px` 宽度、外边距和内边距限制，直接铺满视口；背景只叠加透明星云光晕，不再形成黑色矩形边框。
- `earth-atlas.js` 保持 `?v=4`，星尘轨迹升至 `?v=2`；Service Worker 缓存升至 `our-universe-v56-sparse-stardust`。

## 验收

1. 密码解锁后默认进入“星河”页面，背景为持续流动的旋涡星尘并与全站宇宙背景连续铺满，左右不出现黑色边框；左侧导航仍能切换回忆、此刻和档案。
2. 悬停任一行星时，行星放大并出现名称；点击或触摸后可见同色粒子爆发与私密情话，点击空白处或关闭按钮可关闭。
3. 鼠标移动或手指滑动时出现完整金银拖尾，停止移动后 3 至 5 秒内自然消失；页面交互、抽屉和弹窗不受阻挡。
4. 打开系统“减少动态效果”后，指针星尘与行星引导停用。
