# 2026-07-19 电影式狮子显影

## 调整目标

让流星承担开场第一笔，让狮子从暗金轮廓自然显影，消除六星与完整线稿之间的突变。

## 时序

- 0.20 秒：流星由左侧画外划向银河中心，先唤醒画面。
- 2.00 秒：六颗镰刀星开始连续描线。
- 2.10–7.60 秒：透明狮子从低亮度、低饱和、轻模糊逐帧过渡到清晰完整；六星余辉同步降低。
- 10.00 秒：画面稳定后才显示“轻触星空”。

## 实现

- `playOpeningMeteor()` 替代结尾引导流星。
- 狮子层由每帧 `smoothProgress` 驱动 `opacity`、`blur`、`brightness`、`saturate` 和极小缩放；取消 CSS 的长时 opacity 过渡，避免双重缓动造成拖滞。
- 开场脚本升级为 `lion_background.js?v=19`，缓存升级为 `our-universe-v19-opening-meteor`。
