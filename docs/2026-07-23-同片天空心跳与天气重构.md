# 2026-07-23 同片天空：心跳与天气重构

## 目标

保留“左侧心形、右侧双城市天气”的桌面布局，让在线状态与天气成为同一片夜空中的并列画面。

## 实现

- 无卡片或椭圆边框，整块内容直接铺在星空上；左侧更宽，右侧保留双城市纵向信息。
- 左侧：金色心电线在心形两侧断开。单人显示左半心与“另一颗星光，正在路上”；在线侧的光点沿心电线传到心边缘，抵达时心短促震颤一次；Realtime Database 确认两位不同访客在线后补全右半心。
- 右侧：上海、成都上下排列；每座城市使用线描地标与云层、实时温度、天气状况和固定短句。天气接口不可用时保留完整排版并显示“天空暂时留白”。
- 使用原生 SVG 和 CSS，不新增图片资源；`prefers-reduced-motion` 会停用动态效果。
- 生成的 `assets/backgrounds/celestial-atlas-cloud-drift.png` 直接作为 `#starfield` 的 CSS 默认背景；背景图预加载后，以低幅度 CSS 位移形成云层缓慢漂动，不依赖 JavaScript 才显示。
- `presence-heart.js` 升至 `?v=2`，Service Worker 缓存升至 `our-universe-v53-generated-atlas-default`。

## 验收

1. 宽屏下左侧始终是心形，右侧始终是上海、成都两行天气，页面没有模块外框或椭圆框。
2. 单设备在线只亮左半心；光点从在线侧传到心边缘时，心只震颤一次；第二个不同浏览器在线后才显示完整心形。
3. 无天气 Key、请求超时或单城市失败时，城市插画与文字布局仍完整可见。
4. 首次打开能直接显示背景；更新上线后由 Service Worker 接管并刷新一次，确认缓存显示新版。
