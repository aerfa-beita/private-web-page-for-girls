# 2026-07-22 地球主页面与回忆留痕重构

## 这次确定的体验

- 密码正确后首先进入“地球”，而不是旧 Hero、底部导航或放映机。
- 左侧固定“地图”按钮展开标签抽屉，包含“地球 / 回忆 / 此刻”三个入口；旧的 `01 / 02 / 03` 入口和底部导航保留代码但不再向访客显示。
- 地球是克制的编辑感实体，不采用游戏式 HUD、等级、任务或永久线路。
- 中国区域或地点被选中后，才绘制一条路线；路径由描边动画和沿线移动的光点组成。未选择时没有任何静态线路，避免画面杂乱。
- 回忆页首屏固定展示 6 张拍立得，左下角保留短句；其后是公开留言区、可展开且可再次收起的完整放映机，以及投稿入口。
- 留言按 12 条一页加载。Firebase 连接失败时，公开页面隐藏留言区，不显示“功能不可用”等自曝式提示；本地测试信息仍受私有 `ENABLE_MESSAGE_TESTING` 控制。

## 模块边界

| 文件 | 职责 |
| --- | --- |
| `scripts/ui/earth-atlas.js` | 地球实体、左侧标签抽屉、地点信息与选择后动态路线。 |
| `index.html` | 页面容器、回忆页六张拍立得、留言分页、模块切换与公开降级。 |
| `image_carousel.js` | 完整档案放映机和朋友投稿流程；仅在展开后初始化。 |

`earth-atlas.js` 不直接访问 Firebase；它通过 `window.UNIVERSE_PHOTOS` 读取已有首屏照片，并调用 `window.switchModule()`，避免把导航、DOM、存储逻辑重新耦合到 `index.html`。

## 旅行记忆内容

当前 `EARTH_MEMORIES` 内的“重庆”“上海”及两句文案只是可运行的示例种子，并非对真实旅行事实的断言。正式发布前，在 `scripts/ui/earth-atlas.js` 的 `EARTH_MEMORIES` 中替换为实际去过的城市、对应照片序号和一两句回忆即可；路径动画与展示逻辑不需要改动。

## 验收要点

1. 未解锁时不显示左侧“地图”按钮或抽屉。
2. 解锁后默认显示地球，打开“地图”可在三个标签间切换。
3. 未选中国前无路线；选中后路线描边出现，光点沿路线运行；切换城市时路线与文字同步更新。
4. 回忆页有 6 张拍立得；“展开所有回忆”后按钮变为“收起完整放映机”。
5. 在线确实有两位不同浏览器访客时才显示粒子心形；单人只显示单点。
6. 留言可加载首批 12 条，并可按“加载更早留言”继续读取；线上失败不向访客展示调试报错。

## 与图片存储方案的关系

这次 UI 不改变存储职责：首页 6 张小而关键的照片仍可由 Vercel 提供，完整档案与朋友上传图片使用 Firebase Storage。完整档案迁移与规则发布见 [完整回忆档案 Firebase 迁移](2026-07-22-完整回忆档案Firebase迁移.md)。在 Firebase Console、Vercel 预览都核对成功且项目所有者再次明确授权前，不能删除本地原图，也不能取消它们的 Git 跟踪。
