# 2026-07-19 开场与首页收尾

## 目标

完成本轮 1–6 项网页内收尾：让解锁后的过渡自然、降低首页的工具感、稳定月亮信件入口，并复核移动端。

## 本次改动

- 密码正确后，星图仅作为约两秒的短暂过渡，随后向上漂移并淡出；触摸、Enter、Space、Escape 都可立即跳过。
- 星图离场后派发 `mainExperienceEntered`，开场画布和狮子座图层随即卸载，不会覆盖照片与后续模块。
- 修正静观星图的旋转原点为 SVG 中心 `(350, 350)`，避免拖动时出现偏心旋转。
- 开场时间轴重排为：先出现流星，再连续点亮主星，最后从暗金平滑显出完整狮子；总时长缩短至 9.4 秒。
- 首页入口改为“回到那天 / 写给以后 / 重看瞬间”，底部导航改为更克制的“回忆 / 私语 / 放映”。
- 月亮信件优先读取 `window.__CONFIG__.MOON_LETTERS`；未配置时使用 `LOVE_QUOTES`，每次避免连续重复。
- 移动端收紧静观页与首页入口的间距、字号和宽度，底部导航改为更轻的编辑性样式。
- Service Worker 与开场脚本版本同步升级至 v20，避免旧缓存继续加载 v19 动画。

## 配置

若要使用两人专属月亮信件，在 `config.js` 添加：

```js
window.__CONFIG__ = {
  MOON_LETTERS: [
    '第一句只属于你们的话',
    '第二句只属于你们的话'
  ]
};
```

若不添加，网页仍会使用 `index.html` 内的 `LOVE_QUOTES`。

## 验证

- `node --check lion_background.js` 通过。
- 浏览器实测：输入正确密码后静观页出现，约 2.5 秒内退出，首页入口“回到那天”可见。
- 390 × 844 视口实测：首页与入口宽度均为 342.67 px，无横向溢出。
- 浏览器控制台未发现本轮改动导致的 JavaScript 错误；Firebase Storage 与 Firestore 的远程配置错误仍待外部服务开通处理。
