# 开场降级完整视觉

## 问题

当 Three.js CDN 无法加载，旧逻辑仅显示 CSS 星空并在 15 秒后展示密码入口。标题、月亮与狮子座都会缺失，画面显得像未加载完成。

## 处理

- 页面内置不依赖 Three.js 的完整备用开场：标题、副标题、透明狮子座线稿、星座标记与月亮。
- Three.js 加载失败会立即显示备用开场；外部开场脚本本身不可用时，15 秒兜底也会显示同一画面。
- 正常 Three.js 开场成功时自动隐藏备用层；进入主页面时一并卸载。
- Service Worker 升级为 `our-universe-v22-resilient-opening`，开场脚本版本更新为 `v=21`。
