# V3 星图交互与排版优化

## 调整

- 静观页加入低透明星云层，使用 CSS 多层径向渐变模拟图 A 的天文摄影背景，不引入额外图片或粒子。
- 长文案移出 SVG，改为星图下方三列铭文，避免与星线和日期重叠。
- 狮子座 SVG 可通过鼠标或手指按住左右拖动，在 `-18°` 至 `18°` 范围内缓慢旋转。
- 两张照片碎片改为星图下方布局，避免遮挡星点。

## 性能

拖动只更新 SVG 群组的 `transform` 属性；没有新增动画循环、定时器或粒子。

node --test tests/site-features.test.js
