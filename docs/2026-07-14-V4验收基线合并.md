# V4 验收基线合并

## 目的

将已完成的 V3 草稿从 `feature/universe-v2-roadmap` 合并到 `main`，解决主工作区与隔离工作树内容不一致、主目录无法验收的问题。

## 基线规则

- `D:\MY_Project\web-page` 是唯一主验收基线。
- `feature/universe-v2-roadmap` 保留为历史工作树，不删除也不再直接修改。
- 后续 V4 阶段从主验收基线创建独立工作树开发。
- 草稿通过自动测试和视觉验收前，不合并回主工作区。
- `config.js`、本地照片和其他被忽略的配置不提交到 Git。
