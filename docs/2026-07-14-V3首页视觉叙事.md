# V3 首页视觉叙事改造

## 范围

本次只调整 `index.html` 和 `lion_background.js` 的视觉呈现与开场节奏，保留现有 Firebase、照片、音乐、留言和导航功能。

## 调整内容

- 配色从粉蓝高亮改为深空、暖金与米白，减少渐变和过度发光。
- 首页 Hero 改为“标题 → 相遇天数 → 入口”的单线叙事，加入英文副标题与低干扰的“点亮星河”锚点。
- 移除 Hero 和入口卡片中的主要 emoji，入口以暖金小星点作为视觉标记。
- 狮子座开场改为统一时间轴：深空星点、低亮银河、固定星点逐个亮起并连线、标题与星座名称出现、最后进入密码锁。
- 移除开场中的固定流星，避免多个特效同时争夺注意力。

## 保留项

- `spaceReady` 事件协议和密码锁流程。
- Firebase、照片、音乐、留言、天气及既有导航逻辑。
- 移动端粒子降级与 Three.js 失败回退。

node --test tests/site-features.test.js
