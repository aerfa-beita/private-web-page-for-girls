# 2026-07-19 引导流星与月亮情书

## 问题

六颗镰刀星使用多段独立描线，视觉上会出现不连续；开场结束时底部入口与随机流星没有关系；月亮虽能长按触发情书，但没有过程反馈。

## 调整

- 六颗镰刀星改为单条 `data-sickle-trace` 连续星轨，从第一颗星一笔描到第六颗星。
- 开场结束后先出现一颗由右上飞向入口位置的引导流星，流星结束才触发 `spaceReady` 并显示“轻触星空”。
- 月亮文案改为“长按月亮，收一封情书”；长按时显示环形进度和“愿望正在靠近…”，成功后显示“情书已抵达”并打开随机情书。
- 开场脚本升级为 `lion_background.js?v=17`，缓存升级为 `our-universe-v17-guided-entry`。

## 验证

- `node --check lion_background.js`
- `node --test tests/site-features.test.js`
- `git diff --check`
- 本地预览：确认连续星轨、引导流星后出现入口、月亮长按的进度与情书弹窗。
