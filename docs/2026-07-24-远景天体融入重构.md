# 2026-07-24 远景天体融入重构

## 目标

保持 `celestial-atlas-cloud-drift.png` 的真实星云背景和 Canvas 横向银河不变。将密码后首页的四颗行星从悬浮 UI 卡片调整为远处天体：存在感更低、距离感更强，并减少 HUD、圆形编号和装饰线。

## 实现

- `scripts/ui/earth-atlas.js` 继续使用 `GALAXY_PLANETS` 统一配置四颗行星的位置、尺寸、标题、英文档案名和私密文案。
- 第一束光缩至 56px，采用约 80% 可见度、深暗面与单侧金色晨光，不使用白色描边。
- 梦境之境将核心缩至容器的 60%，外层使用模糊紫色星云包裹，避免完整圆球轮廓。
- 心动轨迹改为暗金、暖白和少量粉紫的低饱和材质，移除红色视觉重心。
- 永恒之约扩大为 112px 暗色气态行星，保留一条极弱的外侧反光；交互轨道仍只在点击该行星后出现。
- 四颗名称改为无边框的“星辰手记”排版。名称、英文档案名默认可见；点击后才展开三行私密文案与该颗的轨道。
- 原有点击粒子爆发、银河 Canvas、全局星尘轨迹和左侧导航不变。
