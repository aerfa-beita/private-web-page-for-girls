# V3 狮子座静观页

## 体验流程

1. Three.js 开场以固定狮子座星位逐颗点亮，连接线使用低透明暖金色。
2. 开场的星图、星座名称与标题在第 6 至 8 秒共同淡出，随后显示密码锁。
3. 密码正确后显示独立的狮子座静观页；用户可停留阅读，再主动进入现有首页。

## 星图内容

静观页以真实狮子座轮廓为骨架，三颗主星承载私人记忆：

- `2025.01.29`：那天，我们第一次走进彼此的心里。
- `2025.07.06`：我们在沙漠里奔跑，把风留在身后。
- `2026.02.10`：重庆的灯亮起时，我们又回到了彼此身边。

沙漠和重庆节点使用现有照片资源作为静态记忆碎片；日期是铭文而不是按钮，不新增数据或交互流程。

## 性能约束

- 未增加粒子数量。
- 不使用持续的 CSS 特效堆叠。
- 复用既有 Three.js 渲染循环和 `spaceReady` 协议。
