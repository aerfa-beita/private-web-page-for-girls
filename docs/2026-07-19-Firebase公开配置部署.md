# Firebase 公开配置部署

## 问题

`config.js` 被 `.gitignore` 排除，以保护天气 Key、AI 地址和私人扩展配置。Vercel 因此无法取得它，线上请求 `/config.js` 返回 404，网页没有 `FIREBASE_CONFIG`，无法启动匿名登录或 Firestore 留言。

## 处理

- 新增可提交的 `firebase-config.js`，仅保存 Firebase Web SDK 的项目识别配置。
- `index.html` 先加载 `firebase-config.js`，再尝试加载仍被忽略的本地 `config.js`。
- `config.js` 继续只用于月亮信、天气与 AI 等私人扩展；缺失时不再影响 Firebase。
- Service Worker 缓存升级为 `our-universe-v21-firebase-config`，并预缓存公开配置文件。

## 安全边界

Firebase Web 配置中的 API key 是客户端项目标识，不是服务端管理员密钥。安全性由 Firestore Rules、Authentication 和 App Check 控制。不得把天气 API Key、OpenAI Key、服务端密钥或私人情话配置放入本文件。
