## 修改内容

### 1. 照片压缩（Vercel 100MB 限制）

**问题**：`assets/Photograph/IMG_20260228/` 共 94 张照片，原始大小 626MB，远超 Vercel 免费额度 100MB，无法部署。

**方案**：≥3MB 的照片用 sharp 压缩到 1200px 宽、80% JPEG 品质。压缩前后对比：

| 阶段 | 照片大小 | 加音乐(27MB)后的总大小 | Vercel 100MB |
|------|----------|----------------------|-------------|
| 原始 | 626 MB | 653 MB | ❌ |
| ≥6MB 压缩（43张）| 137 MB | 164 MB | ❌ |
| ≥3MB 压缩（+21张）| **54 MB** | **82 MB** | ✅ |

原图备份在 `assets/Photograph/IMG_20260228_original/`，不提交 Git。

压缩脚本：`scripts/compress-photos.js`，用法：`node scripts/compress-photos.js`

### 2. config.js 缺失静默失败（G2）

新增 `validateConfig()` 函数，在 `bootstrap()` 最开头调用。天气 Key 或 Firebase 配置缺失时立即更新 UI 为可理解的降级文案，不再永远是"加载中…"。

### 4. 删除星语小助手（Q4）

- 后续版本以服务器时间每 45 秒续期，3 分钟后才视为离线
- 加了加载态和离线提示
- 心跳区域移到导航栏上方固定位置，所有模块可见
