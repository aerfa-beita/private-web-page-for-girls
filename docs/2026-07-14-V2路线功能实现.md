## 外部配置与阻塞

### AI 服务

在部署平台的服务端或云函数中实现 AI 代理，并把相对路径写入本地未提交的 `config.js`：

```js
window.__CONFIG__ = {
  AI_ENDPOINT: '/api/love-message'
};
```

代理服务负责保存模型密钥、鉴权、输入校验、长度限制和速率限制，成功时返回 `{ "message": "..." }`。浏览器不得保存第三方模型密钥。

### Firebase Storage

图片上传仍未恢复。开通 Blaze 计划并创建 Storage 后，再添加 Storage Rules、文件类型和文件大小限制，随后单独恢复上传 UI 和写入逻辑。

### 部署

Vercel 与 `xiahuaaitalk.top` 需要账户授权、项目连接和 DNS 控制权，当前代码仓库无法替代这些外部操作。部署前需将 Firebase 授权域名和天气 API 的域名限制加入生产域名。
