# 2026-07-19 狮子座原图主视觉

## 目标

将开场中难以辨认的手绘狮子线稿替换为透明底的精细金线狮子，同时保留开场、密码与解锁后记忆星图的交互结构。

## 实现

- 以 `assets/Leo/leo-linework-transparent.png` 作为当前主视觉：文件本身透明，不会产生方形贴图背景。
- `lion_background.js` 先逐颗点亮包含轩辕十二的六颗镰刀星，再保留其余辉并浮现精细金线狮子轮廓。
- 标题固定在顶部安全区，狮子座居中，解锁提示固定在底部，三者不重叠。
- 解锁后的 `#constellation-observatory` 复用同一张透明线稿；三颗记忆星仍可点击、键盘聚焦与拖拽旋转。
- `sw.js` 当前为 `our-universe-v17-guided-entry`：HTML、JS、CSS 采用网络优先、离线时回退缓存，并使用 `skipWaiting()` 让新版本尽快接管。

## 透明融合调整

- 移除手绘虚线狮子；以透明金线主视觉融入银河和星空，画面不含任何方形底板。
- 六颗镰刀星采用独立的逐颗点亮与描线动画，避免 Three.js 早期星点「一下全亮」的草率感。
- 使用开场脚本版本 `v=17`，并预缓存透明主视觉，避免旧缓存继续显示旧版轮廓。
