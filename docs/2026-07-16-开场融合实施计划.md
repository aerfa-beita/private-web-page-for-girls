# 开场状态机融合 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 intro、星尘觉醒和狮子座生成串为由 `lion_background.js` 唯一管理的可验证开场状态机。

**Architecture:** `lion_background.js` 继续保有 Three.js 场景，并新增 `window.universeEntrance` 外观接口和 `INTRO → PASSWORD → AWAKENING → LEO → UNIVERSE` 状态转换。`intro.js` 和 `star_awakening.js` 只负责各自的画布动画与事件通知；`index.html` 只负责保留的密码输入、原有业务初始化和对状态机事件的 UI 响应。

**Tech Stack:** HTML5、CSS3、Vanilla JavaScript、Canvas 2D、Three.js r128、Node.js 内置测试运行器、Service Worker。

## Global Constraints

- 不删除 `lock-screen`、首页、生日、音乐、留言、回忆、静观页或原有 Three.js 功能。
- `lion_background.js` 是唯一入口状态机；`index.html` 不得自行串接 intro、星尘和狮子座阶段。
- 保留 `initLionBackground()`，并在 `lion_background.js` 中暴露 `window.universeEntrance`。
- intro 自动播放，点击提示后才进入密码阶段；错误密码保持原有错误文字和抖动。
- 正确密码只能通过 `universeEntrance.unlock()` 进入星尘觉醒；星尘结束必须触发 `leoAwaken`；lion 监听该事件并生成狮子座。
- 所有新增资源加入 `sw.js` 的预缓存清单；更新缓存名称。
- 实施前必须在独立 Git 工作树中完成；不覆盖主工作区已有的未提交文档改动。
- 除非小花先生明确要求，不创建 Git 提交。

- [ ] **Step 1: 重写 `UniverseIntro` 的构造和生命周期**

将组件入口改为以下行为：

```js
class UniverseIntro {
    constructor(options) {
        this.onContinue = options && options.onContinue;
        this.canvas = document.getElementById('intro-canvas');
        this.layer = document.getElementById('intro-layer');
        this.running = false;
        this.frameId = 0;
        this.continued = false;
        this.stars = [];
        this.handleContinue = this.handleContinue.bind(this);
    }

    start() {
        if (!this.canvas || this.running) return;
        this.running = true;
        this.resize();
        this.createStars();
        window.addEventListener('resize', this.resizeBound = () => this.resize());
        this.layer.addEventListener('click', this.handleContinue, { once: true });
        this.layer.addEventListener('keydown', this.handleContinue);
        this.draw();
    }

    handleContinue(event) {
        if (event.type === 'keydown' && event.key !== 'Enter' && event.key !== ' ') return;
        if (this.continued) return;
        this.continued = true;
        this.stop();
        this.hide();
        if (typeof this.onContinue === 'function') this.onContinue();
    }
}
```

`draw()` 使用保存的 `frameId` 调度下一帧；`stop()` 必须取消该帧、移除 `resize` 和 `keydown` 监听器；`hide()` 添加 `intro-hide` 后在过渡结束时移除图层。删除文件末尾自行创建实例的 `DOMContentLoaded` 监听器。

### Task 3: 在 lion_background.js 实现唯一入口状态机

**Files:**

- [ ] **Step 1: 定义入口状态和转换守卫**

在 IIFE 顶层、`initLionBackground()` 之前加入：

```js
var EntranceState = {
    INTRO: 'INTRO',
    PASSWORD: 'PASSWORD',
    AWAKENING: 'AWAKENING',
    LEO: 'LEO',
    UNIVERSE: 'UNIVERSE'
};
var entranceState = EntranceState.INTRO;
var entranceContext = null;
var introController = null;

function isState(state) {
    return entranceState === state;
}
```

`requestPassword()` 只在 `INTRO` 状态执行：切换到 `PASSWORD`、在 `introController` 存在时调用 `introController.hide()`，然后派发一次 `spaceReady`。其他状态直接返回，不能再次派发事件。

- [ ] **Step 2: 用受控阶段替换旧 `introAnimation()` 调用**

保留 `introAnimation()` 函数作为旧视觉工具，但不在 `initLionBackground()` 中调用它。`initLionBackground()` 一开始先启动受控 intro，再加载 Three.js：

```js
function startEntrance() {
    if (window.UniverseIntro) {
        introController = new window.UniverseIntro({
            onContinue: requestPassword
        });
        introController.start();
    } else {
        requestPassword();
    }

    loadThree(createEntranceScene);
}
```

将当前 `loadThree(function () { ... })` 内的完整场景创建逻辑命名为 `createEntranceScene()`，保留原有星层、银河、月亮、爱心星团、流星池、渲染循环、窗口缩放和月亮隐藏情书逻辑。场景创建后保存：

```js
entranceContext = {
    galaxy: galaxy,
    leoGroup: leoGroup,
    moon: moon,
    starLayers: starLayers,
    setFreeMode: function () { freeMode = true; }
};
```

将 `loadThree()` 的 `script.onerror` 从直接派发 `spaceReady` 改为调用 `requestPassword()`；这样 Three.js CDN 加载失败时也会先淡出 intro，再显示保留的密码锁。

- [ ] **Step 3: 接管正确密码、`leoAwaken` 和狮子座生成**

添加以下阶段函数：

```js
function unlock() {
    if (!isState(EntranceState.PASSWORD) || typeof window.starAwakening !== 'function') return;
    entranceState = EntranceState.AWAKENING;
    window.starAwakening();
}

function awakenLeo() {
    if (!isState(EntranceState.AWAKENING) || !entranceContext) return;
    entranceState = EntranceState.LEO;
    revealLeo(entranceContext.leoGroup, 0, function () {
        entranceContext.setFreeMode();
        entranceState = EntranceState.UNIVERSE;
        window.dispatchEvent(new Event('universeReady'));
    });
}

window.addEventListener('leoAwaken', awakenLeo);
```

将原 `introAnimation()` 内部的逐星点亮算法提取为 `revealLeo(leoGroup, progress, onComplete)`：从 0 按帧提升至 1，更新星点、光晕和连线 opacity；结束时保留月亮和现有自由模式，不生成第二个 Three.js 场景。

- [ ] **Step 4: 暴露兼容入口 API**

在文件末尾保留原导出，并紧随其后加入：

```js
window.initLionBackground = initLionBackground;
window.universeEntrance = {
    start: initLionBackground,
    requestPassword: requestPassword,
    unlock: unlock,
    getState: function () { return entranceState; }
};
```

`initLionBackground()` 需防止重复调用：存在 `entranceContext` 或 `lion-background` 容器时直接返回，避免重复 WebGL renderer、事件监听和动画循环。
